# Design Document — Daisy Yuan Personal Homepage

## 1. Project Description

Daisy Yuan Personal Homepage is a responsive personal portfolio website built with HTML5, CSS3, and JavaScript ES6+. The goal is to introduce my background, software engineering experience, projects, and interests to recruiters, engineers, classmates, and other visitors.

The website contains three pages:

- **Home:** Introduction, experience, engineering desk, working process, and interests.
- **Projects:** Selected software engineering projects with interactive filtering.
- **AI Lab:** An AI-generated page with an interactive tradeoff mixer.

The design uses plum and berry-pink colors, responsive layouts, and interactive components to make the website more personal than a traditional résumé.

## 2. User Personas

### Persona 1 — Technical Recruiter

**Goal:** Quickly understand my background, experience, and technical skills.

**Needs:**

- Clear professional information
- Easy navigation
- Quick access to projects
- Responsive design for desktop and mobile

### Persona 2 — Software Engineer / Hiring Manager

**Goal:** Learn more about my technical experience and projects.

**Needs:**

- Meaningful project descriptions
- Technical details
- Easy project browsing and filtering
- Evidence of front-end development skills

## 3. User Stories

### Learn About Me

As a recruiter, I want to quickly understand Daisy's background so that I can determine whether her experience is relevant to a software engineering position.

### Explore Projects

As an engineer, I want to view Daisy's projects so that I can understand her technical interests and experience.

### Filter Projects

As a visitor, I want to filter projects by category so that I can quickly find projects that interest me.

### Use Interactive Features

As a visitor, I want to interact with the Engineering Desk and AI Lab so that I can explore the website in a more engaging way.

### Mobile Access

As a mobile user, I want the website to adapt to my screen size so that I can easily read and navigate the content.

## 4. Design Mockups

The website was designed for both desktop and mobile screens.

The desktop layout uses CSS Grid and Flexbox to organize content into sections and cards. On smaller screens, multi-column layouts change into a vertical layout for easier reading and navigation.

The main design priorities are:

- Simple navigation
- Clear content hierarchy
- Responsive layout
- Accessible controls
- Consistent colors and typography
- Interactive elements

## 5. Accessibility and Technical Design

The website uses semantic HTML, native links and buttons, keyboard-accessible controls, visible focus states, image alt text, and responsive layouts.

The project is front-end only and uses HTML5, CSS3, JavaScript ES6 modules, CSS Grid, and Flexbox. No backend, jQuery, or component framework is used.
